# little wild

A playful, responsive animal wallpaper gallery featuring 100 wallpaper cards, animal filters, search, favorites, previews, and download links.

## Deploy with Vercel

Import this repository into Vercel. It is a static site; leave the build command blank and use the repository root as the output directory. The entry point is index.html.

Wallpaper images are served by Unsplash and need an internet connection.
